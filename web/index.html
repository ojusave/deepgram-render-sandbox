About this demo

Deepgram handles the conversation. It listens and speaks, with a language model that responds to your saved code and real check results.

Render runs your code. Each session gets a separate temporary computer, called a sandbox. It stays open during practice and closes when you finish or after ten minutes.

Audio, conversation, code, and results are processed by Deepgram and its language-model provider. Code also runs on Render. This app keeps your work in server memory for up to an hour, or until restart. Use the included example rather than private information.
