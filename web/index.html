What’s happening behind the scenes?

Deepgram is your voice connection. It listens, speaks, and connects a language model that asks follow-up questions. The coach reads your saved code when you ask about it.

Render is your practice computer. Your code runs in a separate temporary workspace, called a sandbox. The same workspace stays open during your exercise and closes when you finish or after ten minutes.

Audio, conversation, code, and check results are processed by Deepgram and its language-model provider. Your code also runs on Render. This demo holds your code and conversation in server memory for up to an hour, or until the server restarts. Use the sample exercise, not private information.
